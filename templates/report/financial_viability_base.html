B. Methodology

The financial model uses a nominal, post-tax discounted cashflow (DCF) approach over a {{ finance.project_life_years }}-year operating period preceded by a {{ finance.construction_years }}-year construction phase. Revenue is modelled using a fixed PPA at {{ "%.0f"|format(ppa_price) }} £/MWh with CPI escalation. Generation degradation follows a linear 0.5% p.a. schedule. OPEX is escalated at CPI. Corporation tax at 25% is applied to EBITDA less capital allowances. IRR is calculated using Newton-Raphson iteration on the NPV function. Debt sizing uses sculpted repayment targeting {{ "%.1f"|format(debt.target_dscr if debt else 1.3) }}x DSCR. Sensitivity analysis varies four key parameters independently around the base case.
