Biodiversity Net Gain (BNG)
Under the Environment Act 2021, developments must deliver a minimum 10% biodiversity net gain. Solar farms can achieve this through:
  • Wildflower meadow creation between panel rows
  • Native hedgerow planting along site boundaries
  • Habitat corridors connecting existing ecological features
  • Pond and wetland creation for amphibians
BNG assessment required using DEFRA Biodiversity Metric 4.0 by an accredited ecologist.
