# Princeps 3D Twin — Asset Licence Register

This file is the authoritative attribution register for every glTF / GLB model
bundled under `feasi-frontend/public/assets/twin3d/`. Princeps has a legal
obligation under **CC-BY-4.0** to display author credit and a link to the
licence text wherever a CC-BY asset is rendered. The `AttributionFooter`
component in `src/components/twin3d/AttributionFooter.jsx` reads this register
and exposes it as a footer link on the 3D twin.

> **Compliance rule:** every `.glb` that lands in `twin3d/` must have a row
> here BEFORE it is merged to main. If you cannot attribute it, do not ship
> it. Only CC0 / CC-BY-4.0 / Apache-2.0 / Princeps-commissioned licences are
> permitted.

## Adding a new model

1. Add a row to `MANIFEST.csv` with `asset_id, vendor, source_url, licence, target_path`.
2. Add a row to this file with `author`, `retrieved_date`, and concrete
   `source_url`.
3. Run `bash scripts/fetch_twin_assets.sh` (downloads + draco-compresses via
   `gltfpack`).
4. If the asset cannot be fetched, keep the placeholder from
   `scripts/generate_placeholder_glbs.py` until the legal-reviewed real mesh is
   available.
5. Append a `glb_path` value to the registry entry in
   `src/components/twin3d/assets/registry.js` (APPEND ONLY — do not modify
   neighbouring entries).
