# Princeps 3D Twin — Physical Asset Library

This directory is the **canonical glTF asset store** for the Princeps 3D
Digital Twin. Every primitive in the backend `AssetPrimitive` catalogue that
has a real-world 3D mesh ships from here.

All production assets live under `{workload}/{asset_id}.glb` exactly as
referenced by `asset_catalogue.json` `glb_path` fields. `raw/` is for caching
vendor downloads before compression and is `.gitignore`d via
`.gitkeep`-only commits.

## Level of detail (LOD)

Each asset MAY ship up to three LOD tiers. The renderer chooses the tier
based on screen-space size (handled inside `AssetInstancedLayer`).

| Suffix | Target triangle count | Use case |
|---|---|---|
| (none) / `.lod0` | ≤ 40 k | hero zoom, oblique 3D, within 200 m of camera |
| `.lod1` | ≤ 8 k | mid-range (200–800 m) |
| `.lod2` | ≤ 1.5 k | far view / plan view / stats-heavy scenes (> 800 m) |

Example:

```
bess/megapack_2xl.glb         # LOD0 — hero
bess/megapack_2xl.lod1.glb    # mid
bess/megapack_2xl.lod2.glb    # far — a box is fine
```

If only LOD0 exists the renderer uses it at all distances (fine for v1).
Ship at least LOD1 for any asset instantiated more than 50× on a typical site
(BESS containers, PV tables) — memory wins from the smaller mesh dominate any
draw-call cost.

## Compression policy

All production `.glb` files must be compressed with **Draco + meshopt** via
[`gltfpack`](https://github.com/zeux/meshoptimizer/tree/master/gltf):

```
gltfpack -i raw/sketchfab/megapack.glb -o bess/megapack_2xl.glb -cc
```

Flags explained:
- `-cc` : compress both mesh (Draco) and textures (KTX2/BasisU).
- (Implicit) quantised positions + weld + instance reuse.

Target file size: **< 80 KB per model** at LOD0 for any single-object primitive
(≤ 250 KB for the data-centre hall shell). If gltfpack cannot hit that budget,
drop to LOD1 geometry and re-bake.

## Real-world scale requirement

Every bundled model MUST satisfy:

1. **Units = metres** (glTF convention).
2. **Y-up** coordinate system (three.js / deck.gl default).
3. **Model origin = ground-plane footprint centroid** — the layout engine
   places assets at their origin; a Megapack must sit flat on the ground when
   its origin is at world (0, 0, 0), not be buried or floating.
4. **Facing +X** (long axis) when at rotation 0°. The layout engine rotates
   around Y to align with row vectors.
5. **No per-model scale nodes** — meshes should be baked at 1:1. Parametric
   rules in the registry assume cataloue dims match the mesh extents.

You can verify a downloaded mesh with
[`gltf-transform inspect`](https://gltf-transform.dev/):

```
gltf-transform inspect bess/megapack_2xl.glb
# bbox should read roughly (8.8 × 2.9 × 1.8) metres
```

## How to add a new model

1. Add a row to `MANIFEST.csv` (asset_id, vendor, source_url, licence, target_path).
2. Add a row to `LICENSES.md` with author + retrieved_date.
3. Run `bash scripts/fetch_twin_assets.sh` — idempotent, skips existing files.
   Falls back to `generate_placeholder_glbs.py` if download fails.
4. Spot-check with `gltf-transform inspect` that bbox matches the backend
   `AssetPrimitive.dimensions_m`.
5. Append a `glb_path` value to the corresponding entry in
   `src/components/twin3d/assets/registry.js` (APPEND ONLY — the sibling agent
   owns that file's structure).
6. Open a PR. CI must see:
   - entry in `LICENSES.md`
   - entry in `MANIFEST.csv`
   - file size < 80 KB (250 KB for halls)

## Placeholder behaviour

If a `.glb` is missing at runtime, `gltfLoader.loadAssetGLB()` returns `null`
and the `AssetInstancedLayer` falls back to the parametric box / cylinder
defined by the registry `fallback` field. This is the mechanism that keeps the
twin renderable while CC-BY downloads are still in legal review. Placeholders
are also pre-generated by `scripts/generate_placeholder_glbs.py` so every
MANIFEST row already resolves to *something*.

## Attribution in-product

CC-BY licences require visible author credit. We satisfy this via
`src/components/twin3d/AttributionFooter.jsx`, which fetches `LICENSES.md` at
runtime from `/assets/twin3d/LICENSES.md` and renders a gold link in the
twin's bottom-right corner:

> 3D models: Tesla by [Author] (CC-BY-4.0) · Kenney Industrial Kit (CC0) · 12 sources

Clicking the link opens a modal with the full table from `LICENSES.md`.
**Do not** remove or hide this footer — it is a licence condition, not a
design choice.
